**AI-Powered Pneumonia Detection System**

The **AI-Powered Pneumonia Detection System** is a web-based application developed to detect pneumonia from chest X-ray images using Artificial Intelligence and Deep Learning techniques. This project was developed as my **Final Year Project (FYP)** with the aim of improving early detection of pneumonia and assisting healthcare professionals in making faster and more accurate decisions.

This system allows users to upload chest X-ray images and receive automated predictions generated by trained deep learning models. The project includes **two deep learning models** designed to improve prediction accuracy and provide better analysis of pneumonia cases.

The first model is a **Binary Classification Model**, which classifies chest X-ray images into two categories: **Normal** and **Pneumonia**. This model helps determine whether pneumonia is present or not, enabling quick identification of infected patients.

The second model is a **Multi-Class Classification Model**, which provides more detailed classification of pneumonia into different categories or stages. This helps in understanding the severity and progression of the disease and supports better diagnosis.

The system includes several important features such as **user registration and login**, **secure authentication**, **image upload functionality**, **AI-based prediction**, **dashboard for viewing results**, and **report generation**. The interface is designed to be simple and user-friendly so that users can easily upload images and view results without difficulty.

The frontend of the system was developed using **HTML**, **CSS**, and **JavaScript**, while **Firebase** was used for authentication and database management. The deep learning models were developed using **Python**, **TensorFlow**, and **Keras**, utilizing **Convolutional Neural Networks (CNN)** to analyze chest X-ray images and generate predictions.

The workflow of the system begins when a user logs into the system and uploads a chest X-ray image. The uploaded image is then processed and passed through the trained models. The first model detects whether pneumonia exists, and if pneumonia is detected, the second model performs further classification. The prediction results are then displayed on the dashboard, and reports can be generated and stored for future reference.

The dataset used to train the models consists of publicly available chest X-ray images containing both normal and pneumonia-affected lungs. The dataset includes different categories such as **Normal**, **Pneumonia**, **Bacterial Pneumonia**, and **Viral Pneumonia**, which helped improve the learning capability of the models.

This project demonstrates the practical use of Artificial Intelligence in the healthcare field and highlights the potential of machine learning models in assisting medical diagnosis. The system is designed to reduce diagnosis time, improve prediction accuracy, and provide support for early detection of pneumonia.

Future improvements for this project may include increasing model accuracy using larger datasets, deploying the system on cloud platforms, integrating mobile application support, improving the user interface design, and adding real-time medical consultation features.
